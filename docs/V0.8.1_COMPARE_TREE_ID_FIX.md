# v0.8.1 — Compare TREE_ID Type Fix

Bugfix untuk `Compare 2 Periods`.

## Masalah
`read.csv()` dapat menebak `tree_id` numerik sebagai integer pada satu period package dan character pada package lain. `dplyr::full_join()`/`left_join()` kemudian gagal karena tipe key berbeda. SHP juga dapat mengembalikan tipe DBF yang berbeda antarperiode.

## Perbaikan
- `tree_id` pada metrics CSV dibaca eksplisit sebagai `character`.
- `tree_id` pada metrics SHP dinormalisasi sebagai `character` sebelum geometry join.
- ID kosong/NA dan duplikat dihentikan sebelum join.
- Tidak ada perubahan pada P95, T_TECH, peer residual, atau RECHECK/NO_RECHECK.
- Period package v0.8.0 lama tetap dapat digunakan.
