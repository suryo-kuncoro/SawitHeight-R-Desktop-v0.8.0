# v0.8.0 — Optional Master Registration

## Tujuan desain

Master full PPK/GCP tidak lagi dianggap bagian wajib dari setiap periode. Ia adalah jalur koreksi sebelum period processing bila QC menunjukkan target period tidak konsisten.

```text
Target LAS masuk
   ↓
Posisi sudah baik?
 ├─ YA    → skip Registration → Process One Period
 └─ TIDAK → Master Alignment → registered LAS → Process One Period
                                         ↓
                                 Period Package
                                         ↓
                         Compare PREV + CURR package
```

## Kenapa alignment berada di awal

TREE_ID memakai fixed buffer 2 m. Bila XY target salah, melakukan terrain/normalisasi/P95 terlebih dahulu akan mengukur bagian tajuk yang salah. Karena itu registrasi, bila diperlukan, dilakukan sebelum Step ②.

## Metode alignment yang tersedia

### Translation 3D
Median offset matched controls. Direkomendasikan sebagai default bila masalah terutama berupa shift XYZ.

### Rigid 3D
Kabsch/SVD: rotation + translation, scale dipaksa 1. Gunakan jika QC membuktikan rotasi tetapi tidak ada scale drift.

### Similarity 3D
SVD similarity transform: scale + rotation + translation. Gunakan hanya bila scale mismatch benar-benar terindikasi.

## Yang tidak dilakukan

Aplikasi tidak menjalankan blind ICP antara tajuk/periode. Master LAS berfungsi sebagai reference frame dan control point pair menentukan transformasi. Transformasi yang tidak dapat divalidasi tidak dipaksakan.

## QC

Aplikasi melaporkan:
- matched controls;
- control RMSE sebelum dan sesudah transform;
- leave-one-out RMSE bila jumlah control mencukupi;
- scale;
- XYZ translation;
- diagnostic rotation angles;
- per-control residual table.

Optional `Max RMSE gate` dapat diaktifkan pengguna. Nilai 0 berarti hanya report QC, tanpa hard threshold.
