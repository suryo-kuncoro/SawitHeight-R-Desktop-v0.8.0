STEP ① · OPTIONAL

Registration QC / Master Alignment

Dipakai hanya ketika target period tidak konsisten terhadap master full PPK/GCP. Tidak melakukan ICP otomatis.

Target & Master

Prinsip konservatif
Jika hanya ada offset, gunakan Translation 3D. Jangan memakai model lebih kompleks tanpa bukti QC adanya rotasi/scale issue.

Matched Control Points

Transform dihitung dari titik kontrol/stable point yang memiliki ID sama pada target dan master. Format: CSV atau POINT SHP/GPKG/GeoJSON.

Untuk file spatial POINT, XY diambil dari geometry. Z diambil dari geometry Z jika tersedia; jika tidak, gunakan field Z di atas.

Registration QC

0 = tidak ada hard gate. Aplikasi tetap menghitung RMSE before/after dan leave-one-out RMSE. Bila gate > 0 dan QC melebihi nilai tersebut, registered LAS tidak dibuat.
